# DK Seed Bank

DK Seed Bank is a free, browser-based seed inventory and gardening recordkeeping application by DK Softworks. It is designed for serious gardeners and preparedness-minded seed collectors, not as a game.

It helps you organize and search seed varieties, track packets and saved seed lots, view planting information and reference photos, plan sowing, record planting and germination, manage watering and harvest records, monitor seed viability and storage, and back up your records. The interface is available in English and Russian.
